# Common Issues Runbook

This document provides troubleshooting guidance for common issues encountered in the BookMe Portal application.

## Map Issues

### Issue: Map not loading or showing "Kunne ikke laste kart"
**Root Cause**: Missing or invalid Mapbox token
**Action**:
1. Verify `VITE_MAPBOX_TOKEN` is set in `.env` file
2. Ensure the token has proper permissions for the Mapbox account
3. Check browser console for Mapbox-specific error messages
4. Verify network connectivity to Mapbox API endpoints

### Issue: Facility markers not appearing on map
**Root Cause**: Invalid coordinates or geocoding failure
**Action**:
1. Check that facilities have valid `location` data in the database
2. Verify coordinates are within valid ranges (lat: -90 to 90, lng: -180 to 180)
3. Test geocoding functionality with sample addresses
4. Check browser console for coordinate validation errors

## Authentication Issues

### Issue: Unable to login or session expires frequently
**Root Cause**: Supabase configuration issues or network problems
**Action**:
1. Verify `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in `.env` file
2. Check network connectivity to Supabase endpoints
3. Verify Supabase project is not rate-limited
4. Check browser console for authentication errors

### Issue: Unauthorized access to admin features
**Root Cause**: Incorrect role assignments or RBAC configuration
**Action**:
1. Verify user has proper roles in the organization
2. Check that RBAC policies are correctly configured in Supabase
3. Verify user is assigned to the correct organization
4. Test role-based access with different user accounts

## Data Issues

### Issue: Facilities not appearing in search results
**Root Cause**: Database filtering or publication status issues
**Action**:
1. Verify facilities have `published: true` status
2. Check that facilities belong to the correct organization
3. Verify search filters are correctly applied
4. Check database queries for proper indexing

### Issue: Booking data inconsistencies
**Root Cause**: Race conditions or database transaction issues
**Action**:
1. Verify booking creation follows proper transaction patterns
2. Check for concurrent access to booking data
3. Review booking validation logic
4. Monitor database for constraint violations

## Performance Issues

### Issue: Slow page loading times
**Root Cause**: Bundle size, network latency, or database query performance
**Action**:
1. Analyze bundle size using `stats.html` generated by bundle analyzer
2. Check network tab for slow API requests
3. Review database query performance with Supabase query analyzer
4. Implement proper caching strategies

### Issue: Memory leaks or excessive resource usage
**Root Cause**: Uncleaned subscriptions or event listeners
**Action**:
1. Check for proper cleanup of useEffect hooks
2. Verify Mapbox map instances are properly destroyed
3. Review WebSocket and real-time subscription cleanup
4. Monitor browser performance tools for memory growth

## Build and Deployment Issues

### Issue: Build failures during CI/CD
**Root Cause**: Type errors, linting issues, or missing dependencies
**Action**:
1. Run `pnpm run type-check` locally to identify TypeScript errors
2. Run `pnpm run lint` to identify code quality issues
3. Verify all dependencies are properly listed in `package.json`
4. Check GitHub Actions logs for specific error messages

### Issue: Production deployment errors
**Root Cause**: Environment configuration or runtime issues
**Action**:
1. Verify all required environment variables are set in production
2. Check browser console for runtime errors
3. Verify Supabase RLS policies are correctly configured
4. Review server logs for deployment-specific issues
