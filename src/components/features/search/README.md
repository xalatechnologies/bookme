# Search Domain

Advanced search and filtering features.

## Structure

```
search/
├── components/
│   └── SearchFilter.tsx
├── hooks/
├── types.ts
├── constants.ts
├── index.ts
└── README.md
```

## Key Features

- Full-text search
- Advanced filters
- Category filtering
- Date range selection
- Price range filtering

## Usage

```tsx
import { SearchFilter } from '@/components/features/search';
import { hasSearchPermission } from '@/components/features/search';
```
